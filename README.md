# GalaxySim

Галактический экономический симулятор на Go.

**Стадия: ~30% — далеко до завершения.**

Мир живёт сам: планеты производят и потребляют, трейдеры и караваны возят товары,
пираты грабят, банкиры перераспределяют деньги. Цель — мультиплеерная экономика
(общий рынок) с горизонтом до 12000 лет.

## Стек

- Go 1.22 (`net/http`, `math/rand`)
- Ванильный JS (`index.html`), без фреймворков
- Shared memory (Windows) для внешнего viewer
